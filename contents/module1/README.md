# Module 1 Practice Data (BIO2110)

This folder holds the practice files for Module 1.

What this module contains:
- ehr_demo/raw/      synthetic CSV tables for previewing and navigation practice
- ehr_demo/docs/     a data dictionary and short notes file
- ehr_demo/results/  empty output folder (you will create files here later)
- practice/          files for safe file operations (mkdir, touch, cp, mv, rm)
- scripts/           the setup script for Lab Activity 1 and Practice Assignment 1

Book Chapter 1 (Binder) uses the folders above as they are.

Lab Activity 1 and Practice Assignment 1 (Google Cloud Shell) use a separate
workspace named lab_activity/. Create it from the repository root with:
  bash contents/module1/scripts/setup_module1_lab_activity.sh

Beginner routine (repeat often):
1) pwd   (Where am I?)
2) ls -F (What is here?)
3) Move with cd, then re-check pwd and ls -F

Professional habit:
- Never edit “raw” data in place.
- Copy raw files into a workspace before changing anything.

AI in Module 1:
- Learn and practice the Unix skills first, without AI.
- You will use an AI assistant in one short activity at the end of Lab Activity 1.
- Never paste private or sensitive data into AI tools.
